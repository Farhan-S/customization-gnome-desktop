# Pixegami Chrome theme

Navy/mint theme on the Pixegami palette (`#0C1C25` / `#86FFAF`), matching the
GNOME desktop, the Dracula GTK recolor and the Bibata cursor.

Chrome loads this **unpacked, straight from this directory** (Profile 1,
extension id `hcfjmofcpgpgnafenggolenfaocclgkm`). Editing these files edits the
live theme - there is nothing to copy anywhere.

To apply a change: `chrome://extensions` -> reload the Pixegami Theme card, or
just restart Chrome. `Cached Theme.pak` is Chrome's own compiled cache; it is
gitignored and regenerates itself.

## What a Chrome theme can and cannot do

The theme API is only four keys - `colors`, `images`, `tints`, `properties`.
There is **no way for an extension to change Chrome's shape, corner radius,
tab geometry, spacing or layout**. Those are drawn by the browser. So "capsule
tabs" and "tighter layout" cannot be set here, and no theme on the Web Store
does it either.

Chrome 151 already draws capsule tabs and a pill omnibox. What this theme does
instead is make that existing geometry *read* clearly, by giving every surface
its own value so the shapes separate by contrast rather than by outline:

| surface                | colour    | why                                  |
|------------------------|-----------|--------------------------------------|
| window frame           | `#08151D` | deepest, so the tab strip recedes    |
| inactive tabs          | `#0A1820` | a hair above the frame               |
| toolbar + active tab   | `#0C1C25` | the identity colour, the main plane  |
| omnibox / buttons      | `#152535` | lightest, so the pill lifts forward  |
| accent                 | `#86FFAF` | icons, links, focus ring only        |

Text is soft white (`#E8F4F0`) rather than mint. Mint stays an accent - used on
icons, links and the focus ring - which is what keeps it from reading as loud.
If you want the old all-mint text back, set `tab_text`, `toolbar_text` and
`omnibox_text` to `[134, 255, 175]`.

## Texture

`images/` holds five tiles generated by `generate-textures.py`: a 45-degree
hatch at about 2% opacity plus a trace of noise, enough to kill the flatness of
a solid fill without reading as a pattern.

Chrome tiles the frame, toolbar and tab images horizontally and anchors them to
the top, so those are seamless left-to-right only and carry a slight vertical
gradient for depth. The new tab page tile repeats both ways, so it is seamless
on both axes and has no gradient. Tile widths are multiples of the 8px hatch
spacing, which is what makes the diagonal wrap invisibly.

To change the texture, edit the constants at the top of the script and re-run:

```sh
python3 generate-textures.py
```

Then reload the extension. Verify the manifest still packs before committing:

```sh
google-chrome --pack-extension=/home/farhan/.dotfiles/config/chrome/pixegami-theme
```
